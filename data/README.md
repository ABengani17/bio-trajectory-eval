# Data

`trajectories.jsonl` is the seed trajectory dataset. Each line is one validated trajectory.

Stage A includes six items, two per difficulty tier. The small size is intentional. It fixes the schema and lets reviewers inspect the methodology before the harness and scoring code are added.

The items use safe proxy domains only. They do not contain organism engineering instructions, operational protocol details, sequences, dose information, delivery instructions, or hazardous-agent content.
